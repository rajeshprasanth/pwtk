# Quantum ESPRESSO Tools & Examples Index

This folder contains multiple **tools and example datasets** for plotting, analysis, and post-processing of **Quantum ESPRESSO** outputs. Each subfolder hosts a specific tool or example workflow, along with configuration files and example data.

Use this README to **quickly locate tools, understand their purpose, and run examples**.

---

## Tools & Description

| Tool / Folder         | Purpose                                                                                              | Example System              |
| --------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------- |
| **plot_qe_bands_dos**   | Generates band structure, DOS, and combined plots from QE outputs using a config-driven shell script | BN_MoS2, MoS2_WSe2          |
